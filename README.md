Code and data for the Perspective "Hidden redox legacies in apparently recovered soils" by M. Ghotbi, B. C. Kolody, M. Ghotbi, M. F. Breed, J. A. Gilbert and E. Holtgrewe-Stukenbrock (submitted to *Nature Communications*, manuscript NCOMMS-26-099131).

The Perspective introduces out-of-step recovery: bulk conditions (moisture, temperature, pH, O₂, Eₕ) can return while the internal state that sustains a function, its capacity (electron reserve), connectivity (access to it) and kinetics (reaction rates), recovers on different timescales from bulk conditions or among its components. Three limiting calculations (equations (1)–(3), main Box 1) show the consequences, and a predictive test (Fig. 6) asks whether measuring that state improves prediction. This repository contains only what is needed to reproduce the figures and quoted numbers; it is not a general modelling package.


The repository provides the plotting materials and numerical checks for the analytical examples and the published-data reanalyses:

## Reproduce

Everything at once (Python required; R checks run if `Rscript` is available. If OpenCV is unavailable, the runner preserves the bundled final Supplementary Figure 1a artwork and regenerates the analytical panels):

    pip install -r requirements.txt
    bash run_all.sh

Or step by step:

Python (3.10 or later):

    pip install -r requirements.txt
    cd python
    python fig1_concept.py
    python fig5_evidence.py
    python fig6_test.py
    python figS1a_relabel_artwork.py
    python figS1_worked_example.py b
    python figS1_compose.py
    python figS2_predictions.py
    python figS3_capacity_inventory.py
    python figS4_reanalysis_detail.py
    python verify_reported_values.py      # must print ALL PASS
    python verify_yu_source.py           # current Fig. 5d and Supplementary Fig. 3

R (base R only; an independent check of the same values):

    cd R
    Rscript verify_reported_values.R      # checks the empirical and analytical values quoted in the text
    Rscript verify_theory.R               # checks the analytical examples in Supplementary Note 1
    Rscript independent_math_check.R
    Rscript verify_weak_escape.R

Code-generated figures are written to `figures/` as PDF, PNG (600 dpi) and SVG. Figure 6 is provided as the exact full author PNG, with a separate vector PDF, SVG and 600 dpi PNG for the independently reproduced interval panel. Figure 1 panel c uses purely schematic trajectories, not a fit to source data; panel titles are given in the figure legend rather than on the figure.

## Contents

- `run_all.sh`: regenerates all figures and runs all checks.
- `python/theory.py`, `R/theory.R`: closed-form results for equations (1)–(3) in main Box 1: fixed-pool exchange, the crossing time of two pools, cumulative escape with a delayed sink, and carry-over between events.
- `python/style.py`: shared figure style.
- `R/extract_sennett_final_incubation.R`, `R/derive_evidence_metrics.R`, `R/verify_primary_tables.R`: extraction of the published source-data workbooks and derivation of the integrals, half-times and ratios used in Fig. 5 and Supplementary Fig. 4.
- `data/primary_source_workbooks/`: the published source-data extracts used (Li et al. 2025; Liu et al. 2025; Patzner et al. 2020; Sennett et al. 2024; Yu et al. 2026, source-data workbooks MOESM4 and MOESM5). `data/yu_2026_microbial_reduction_eec.csv` gives, per sediment, EAC lost and EDC gained after 5 days of microbial reduction (initial minus end values from MOESM5, Figure S9; s.d. propagated from duplicates) and the Mössbauer clay-Fe(II) percentages (MOESM4, Figure 5) used to group sediments by Fe(III) reduction (increase > 5 percentage points). Panel d replaces the earlier Patzner et al. reactive-Fe panel; that CSV is retained for provenance.
- `data/*.csv`: extracted tables and derived values. Column definitions and integration windows are described in Supplementary Note 2 and Supplementary Table 1.

## Source data and reuse

No new measurements are reported. The source workbooks are third-party data from the publications below and are included only as the extracts needed to reproduce the figures. Please cite the original publications when reusing the measurements.

- Li, C. et al. Rhythmic radial oxygen loss enhances soil phosphorus bioavailability. *Nat. Commun.* 16, 4413 (2025). https://doi.org/10.1038/s41467-025-59637-x
- Liu, F. et al. Abiotic processes dominate short-term carbon emissions in sandy soils following rewetting. *Commun. Earth Environ.* 6, 733 (2025). https://doi.org/10.1038/s43247-025-02733-z
- Yu, C. et al. Deciphering the origin of electron exchange capacities in floodplain sediments. *Commun. Earth Environ.* 7, 290 (2026). https://doi.org/10.1038/s43247-026-03307-3
- Patzner, M. S. et al. Iron mineral dissolution releases iron and associated organic carbon during permafrost thaw. *Nat. Commun.* 11, 6329 (2020). https://doi.org/10.1038/s41467-020-20102-6
- Sennett, L. B. et al. Determining how oxygen legacy affects trajectories of soil denitrifier community dynamics and N₂O emissions. *Nat. Commun.* 15, 7298 (2024). https://doi.org/10.1038/s41467-024-51688-w

One complete-record integral (long-anoxic history, Sennett et al.) differs from the value in the source article; integrating the LA records to 42.0 h reproduces the published value (`python/la_integral_audit.py`), but the source does not state its integration bounds, so the discrepancy is unresolved. A difference confined to the integration endpoint after 24 h would not alter the separately calculated 1–24 h integrals. The discrepancy is documented in Supplementary Note 2 and `data/sennett_integration_definition_comparison.csv`.
