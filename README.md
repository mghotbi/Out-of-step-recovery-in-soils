## Reproduce

Python (3.10 or later):

    pip install -r requirements.txt
    cd python
    python fig1_concept.py
    python fig5_evidence.py
    python fig6_test.py
    python figS1_predictions.py
    python figS2_reanalysis_detail.py
    python verify_reported_values.py      # must print ALL PASS

R (base R only; an independent check of the same values):

    cd R
    Rscript verify_reported_values.R      # checks the empirical and analytical values quoted in the text
    Rscript verify_4R.R                   # checks the analytical examples in Supplementary Note 1
    Rscript independent_math_check.R
    Rscript verify_weak_escape.R

Figures are written to `figures/` as PDF, PNG (600 dpi) and SVG, in Arial (or the metrically identical Liberation Sans) at 7 pt.

## Contents

- `python/theory.py`, `R/theory_4R.R`: closed-form results for equations (1)–(3): fixed-pool exchange, the crossing time of two pools, cumulative escape with a delayed sink, and carry-over between events.
- `python/style.py`: shared figure style.
- `R/extract_sennett_final_incubation.R`, `R/derive_evidence_metrics.R`, `R/verify_primary_tables.R`: extraction of the published source-data workbooks and derivation of the integrals, half-times and ratios used in Fig. 5 and Supplementary Fig. 2.
- `data/primary_source_workbooks/`: the published source-data extracts used (Li et al. 2025; Liu et al. 2025; Patzner et al. 2020; Sennett et al. 2024).
- `data/*.csv`: extracted tables and derived values. Column definitions and integration windows are described in Supplementary Note 2 and Supplementary Table 1.

## Source data and reuse

No new measurements are reported. The source workbooks are third-party data from the publications below and are included only as the extracts needed to reproduce the figures. Please cite the original publications when reusing the measurements.

- Li, C. et al. Rhythmic radial oxygen loss enhances soil phosphorus bioavailability. *Nat. Commun.* 16, 4413 (2025). https://doi.org/10.1038/s41467-025-59637-x
- Liu, F. et al. Abiotic processes dominate short-term carbon emissions in sandy soils following rewetting. *Commun. Earth Environ.* 6, 733 (2025). https://doi.org/10.1038/s43247-025-02733-z
- Patzner, M. S. et al. Iron mineral dissolution releases iron and associated organic carbon during permafrost thaw. *Nat. Commun.* 11, 6329 (2020). https://doi.org/10.1038/s41467-020-20102-6
- Sennett, L. B. et al. Determining how oxygen legacy affects trajectories of soil denitrifier community dynamics and N₂O emissions. *Nat. Commun.* 15, 7298 (2024). https://doi.org/10.1038/s41467-024-51688-w

One complete-record integral (long-anoxic history, Sennett et al.) differs from the value in the source article; integrating the LA records to 42.0 h reproduces the published value (`python/la_integral_audit.py`), but the source does not state its integration bounds, so the discrepancy is unresolved. A difference confined to the integration endpoint after 24 h would not alter the separately calculated 1–24 h integrals. The discrepancy is documented in Supplementary Note 2 and `data/sennett_integration_definition_comparison.csv`.
